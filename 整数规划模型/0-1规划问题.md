# 指派问题

这个问题与**背包问题**不同之处在于它是1对1的约束
**背包问题**是1对多的约束强调多个物体对单一资源的竞争
**指派问题**是个体分配到不同资源的最优解

**例题：**
n项任务，需要n个人完成。cij表示分配第i个人去完成第j项任务的费用
问如何指派，总费用最小？

1. 决策变量：派人去哪？（0-1变量：去还是不去某项任务？）

# 旅行商问题（货郎担问题）
# (TSP模型)

**例题**
推销员，从v1出发，访问v2,v3...,vn各一次，最后返回vi，已知从vi到vj的旅费为cy
如何使得总旅费最少？

1. 决策变量：从vi城市进不进入vj?
![[Pasted image 20260610220240.png]]

2. 约束条件：
- 每个城市进入一次：x和为1
 ![[Pasted image 20260610220408.png|234]]
- 每个城市离开一次
![[Pasted image 20260610220437.png]]

- **确保解中不会出现不包含起点（节点1）的独立子回路**
- ![[Pasted image 20260610220508.png]]
解释：
- ui 是辅助连续变量，代表节点 ii 在路径中的访问顺序
（u1​=0，且 1≤ui≤n−1 对于 i≥2）；
- 若xij=1（连接），则uj​≥ui​+1，保证了有次序的被访问
- 如果没有，就可能出现多个解
- 1 → 3 → 1（一个小回路）2 → 4 → 5 → 2（另一个小回路）
- 这个问题与**指派问题**不同的点就在于是一条单一回路，而不是独立的小回路
-  **指派问题**：1→2, 2→1, 3→4, 4→3  
    这满足每个节点出度=入度=1，但它是两个长度为2的子回路（1-2回路和3-4回路），并不是一个包含所有4个节点的大回路。
