指每条边（或弧）都被赋予了一个数值（称为**权值**或**权重**）的图。这些权值通常表示实际意义，如距离、成本、时间、容量、概率等。

## 形式化定义

设**图** G=(V,E)，其中 V 是顶点集，E 是边集。若存在一个函数 w:E→R（或其他数集），将每条边 e∈E映射为一个实数 w(e)，则称 G 为**赋权图**。对于有向图，每条弧也有类似的权重函数。

称w(e)为**权值（或权重）**
w(e)的权重是可以自己根据事件来定义的

举例：
- 在城市路线图中，`w(A, B) = 5` 表示从 A 到 B 的路程是 5 公里。
    
- 在通信网络中，`w(路由器X, 路由器Y) = 0.8` 可能表示这条链路的可靠度是 0.8。
    
- 在社交网络中，`w(用户u, 用户v) = 12` 可能表示两人互动的次数。

### 一般来说 V 顶点集就是事件集，E就是事件之间交互的集

## 表示方法

- **邻接矩阵**：使用 ∣V∣×∣V∣的矩阵，其中 $A [i] [j]$ 存储从顶点 i 到顶点 j 的边的权重（若无边则常用 ∞ 或特殊值表示）
	A到A=0

举例：一个赋权图
    A --2--  B
    |            |
    4           3
    |            |
    C --1-- D
**则临接矩阵是**
	    A   B   C   D
	A   0   2   4   ∞
	B   2   0   ∞   3
	C   4   ∞   0   1
	D   ∞   3   1   0

- **对比无权图**：矩阵中的 `A[i][j] = 1` 表示顶点 i 到顶点 j **有**边；`0` 表示**没有**边
    
- **邻接表**：每个顶点维护一个列表，列表中每个元素包含相邻顶点及对应边的权重。
    

## 常见应用

- **最短路径问题**：如 Dijkstra 算法、Bellman‑Ford 算法求解两点间最小权重和路径。
    
- **最小生成树**：如 Kruskal、Prim 算法求连通赋权无向图的总权重最小的生成树。
    
- **网络流**：边的权重作为容量或费用。
    
- **旅行商问题**：城市间距离作为权重，寻找最短回路。
    
- **社交网络分析**：边的权重表示交互强度或亲密度。
    

## 示例

下图是一个简单赋权无向图：

    A --2-- B
    |       |
    4       3
    |       |
    C --1-- D

边 AB 权重 2，AC 权重 4，BD 权重 3，CD 权重 1。

若赋予方向，则成为赋权有向图，权重可能不对称（如 A→B 权重 5，B→A 权重 3）。
