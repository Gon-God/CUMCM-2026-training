# 计划网络图

将消耗时间或者资源的行为称为**作业**

称作业的开始和结束为**事件**

![[Pasted image 20260613175648.png]]


称初始事件到最终事件的一条路为**路线**

有累计作业**时长**最长的路线为**关键路径**

t(i,j) 表示作业 (i,j) 所需的**工时**（或持续时间、工期）。

- 它是以事件 i 为起点、事件 j 为终点的那项任务从开始到完成所需要的**时间长度**。
    
- 例如，若作业 (i,j) 是“浇筑混凝土”，需要 5 天，那么 t(i,j)=5。


---

事件j的最早可以发生的时间为$t_E(j)$

- 如果j是起点，那么$t_E(j)$为任务最早开始可能开始的时间
	
- 如果j是终点，那么$t_E(j)$为任务最早开始可能结束的时间

**计算**
![[Pasted image 20260613180351.png]]
t(i,j)为事件i与事件j的作业时间耗时


事件i的最晚可以发生的时间为$t_L(i)$

- 如果事件 i 是一个**起点**，那就是任务最晚必须开始的时间。
    
- 如果事件 i 是一个**终点**，那就是任务最晚必须完成的时间。

计算
![[Pasted image 20260613180746.png]]


在同一个网络图中，每个作业（箭头）(i,j) 都有：

- tES(i,j)：**最早可能开工时间**（Earliest Start）
    
- tEF(i,j)：**最早可能完工时间**（Earliest Finish）
    
- tLS(i,j))：**最迟必须开工时间**（Latest Start）
    
- tLF(i,j)：**最迟必须完工时间**（Latest Finish）
![[Pasted image 20260613181233.png]]
### 递推计算（从前往后）

- 从整个项目的起点（事件1）出发的所有作业 (1,j)(1,j)：
    
    tES(1,j)=0
- 对于其他作业 (i,j)，它的紧前作业是那些进入事件 ii 的作业 (k,i)。  
    作业 (i,j) 最早什么时候能开始？  
    要等到所有紧前作业 (k,i) 都完成，也就是取这些紧前作业的**最早完工时间**的最大值：
    
    tES(i,j)=max⁡k{tEF(k,i)}
    
    而 tEF(k,i)=tES(k,i)+t(k,i)，所以也可以写成：
    
    tES(i,j)=max⁡k{tES(k,i)+t(k,i)}
- 然后：
    
    tEF(i,j)=tES(i,j)+t(i,j)tEF​(i,j)=tES​(i,j)+t(i,j)
![[Pasted image 20260613181959.png]]
### 递推计算（从后往前）

- 所有进入终点事件 n 的作业 (i,n)：  
    它们必须按时完工，最迟完工时间 tLF(i,n) 就等于总工期（即 tE(n)）：
    
    tLF(i,n)=总工期
- 对于其他作业 (i,j)，它后面紧跟着若干作业 (j,k)。  
    作业 (i,j) 最迟什么时候必须完工？  
    它完工后，后面的作业才能开始。为了保证后续作业(j,k) 能按它们的最迟开工时间开始，作业 (i,j) 的完工时间不能晚于：
    
    tLF(i,j)=min⁡k{tLS(j,k)}
    
    因为后面的每个作业 (j,k) 都有它的最迟开工时间 tLS(j,k)，而 tLF(i,j)就是这些最迟开工时间里的最小值（取最小是为了满足所有后续作业的要求）。
    
- 然后：
    
    tLS(i,j)=tLF(i,j)−t(i,j)
