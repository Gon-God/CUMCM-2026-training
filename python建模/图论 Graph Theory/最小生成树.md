
**我怎么样用最小的路径把所有点联通起来？**

应用：
想象你在规划一个城市的自来水管网。你需要用管道把“A、B、C、D”四个小区都连接起来（连通性），但为了省钱，要铺设的管道总长度越短越好（最小化）
有圈就是在浪费资源

**树**：联通的**无圈**图

![[Pasted image 20260611223631.png]]
生成树：给定一个包含 n 个顶点的**连通图**，它的生成树是指一个包含了原图所有 n 个顶点，但只保留 n−1 条边的**树**。
最小生成树：边权之和最小的树
有圈就u'sus
