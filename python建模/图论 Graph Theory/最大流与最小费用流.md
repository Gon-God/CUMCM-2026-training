
最大流问题：即物资流，现金流，车辆流顶点。如何安排使得流量最大化？

1. **网络**：一个由节点和带容量的有向边构成的图。
    
2. **源点（Source）**：流量的起点，只有流出。
    
3. **汇点（Sink）**：流量的终点，只有流入。
    
4. **容量（Capacity）**：每条边上允许通过的**最大**流量。
    
5. **流（Flow）**：实际分配的流量，必须满足：
    
    - 每条边的流量不超过容量。
        
    - 除源点和汇点外，每个节点的流入量等于流出量（流量守恒）。
        

**一个通俗的例子：城市水管网络**

想象一个自来水厂（源点）要往居民区（汇点）送水，中间经过一系列水管（边），每根水管有固定的最大通水量（容量）。问：在不超任何水管容量的前提下，居民区每秒最多能收到多少水？这个最大值就是“最大流”。

**定义**：
一个有向图D=(V,A), 在V中指定一点，称为**收点**或者**汇**，记为v1。
这点只有进入的弧，没有出去的弧

其余点称为**中间点**

对于每一条弧$（vi,vj）\in A$
对应由一个$c(vi,vj)\ge 0$，称为弧的容量，即每条弧能通过的最大流量

将有向图D记为一个网络，记作D=(V,A,C)
其中C={cij}

流：一个函数f={fij}={f(vi,vj)}为弧(vi，vj)
上的流量

流出量：$\sum\limits_{j:(v_i,v_j)\in A} f_{ij}$

流入量$\sum\limits_{k:(v_k,v_i)\in A} f_{ki}$

- **可行流**：
	1. 容量限制：$0\le f_{ij} \le  c_{ij}$
	2. 对于中间点：流出量=流入量
	$\sum\limits_{j:(v_i,v_j)\in A} f_{ij}-\sum\limits_{k:(v_k,v_i)\in A} f_{ki} = 0$
	3. 对于发点有
	 $\sum\limits_{j:(v_i,v_j)\in A} f_{ij}=v$
	4. 对于收点有
	$\sum\limits_{k:(v_k,v_i)\in A} f_{ki}=v$

于是有线性规划：

饱和流：fij=cij
非饱和流：$fij<cij$

零流：fij=0
非零流：fij>0
前向弧：由发电到收点的方向,记$\mu^*$
后向弧:反方向，记为$\mu^-$

# Ford-Fulkerson(标号法)

**在残余网络中反复寻找增广路径，直到无法找到为止**

### 1. 核心思想：利用“残余网络”和“增广路径”

- **残余网络**：在原始网络的基础上，每条边增加一个“反向边”，用于记录已经用掉的流量可以被“退回”或“调整”的余地。
    
    - 对于一条容量为 c、当前流量为 f 的边：
        
        - 正向残余容量 = c−f（还可以增加的流量）
            
        - 反向残余容量 = f（可以回退的流量，相当于为之前的流量提供“反悔”机会）
            
- **增广路径**：在残余网络中，从源点 s 到汇点 t 的一条路径，且路径上**每条边的残余容量都大于 0**。沿着这条路径我们可以推送额外的流量。

### 2. 算法步骤

1. **初始化**：所有边的流量设为 0。
    
2. **循环**：
    
    - 在当前**残余网络**中，寻找一条从源点到汇点的**增广路径**（可以用DFS、BFS等图搜索算法）。
        
    - 如果找不到，退出循环。
        
    - 如果找到：
        
        - 找出该路径上**最小的残余容量** Δ（即该路径能增加的最大流量）。
            
        - 沿着这条路径，对**每条正向边**增加 Δ 流量，对**每条反向边**减少 Δ 流量（等价于更新残余网络）。
            
        - 总流量增加 Δ。
            
3. **输出**：最终的总流量即为最大流。

# 例子


原始网络：  
s→A 容量 5  
A→t 容量 5  
s→t 容量 5

1. **初始**：所有流量 0。残余网络就是原图（反向边容量 0）。  
    找一条路径：s→A→t，最小残余容量 = 5。  
    沿路径加 5：
    
    - 边 s→A：流量 5，正向残余 0，反向残余 5
        
    - 边 A→t：流量 5，正向残余 0，反向残余 5  
        总流量 = 5。
        
2. **现在残余网络**：
    
    - 原正向边 s→A 容量 0（不能用），但反向边 A→s 容量 5
        
    - 原正向边 A→t 容量 0，反向边 t→A容量 5
        
    - 还有一条边 s→t 容量 5（未用过）  
        现在要找新路径：s→t（直接），残余容量 5，加 5。  
        总流量 = 10，达到最大。

# 例子：

![[Pasted image 20260613161023.png]]

`flow_value, flow_dict = nx.maximum_flow(G, s, t, capacity='capacity')`
提供了最大流量算法

其中flow_value是最大流量值
flow_dict提供了每个边的流量

G为nx的网络
s是G里面源点的数据
t是G里面汇点的数据

```python
import numpy as np
import networkx as nx
import pylab as plt

L = [(1,2,6),(1,3,4),(1,4,5),(2,3,3),(2,5,9),(2,6,9),
    (3,4,5),(3,5,6),(3,6,7),(3,7,3),(4,3,2),(4,7,5),
    (5,8,12),(6,5,8),(6,8,10),(7,6,4),(7,8,15)]

G=nx.DiGraph()
G.add_weighted_edges_from(L, weight='capacity') #流问题边的权重创建为'capacity'
G.add_nodes_from(range(1,9))
value, flow_dict = nx.maximum_flow(G,1,8) #求最大流

##邻接矩阵
n = len(flow_dict)
adj_mat = np.zeros((n,n),dtype=int) #创建一个矩阵
for i, adj in flow_dict.items(): #items函数将字典变为key 和value组成的列表
	for j, weight in adj.items():
		adj_mat[i-1,j-1]=weight

print('邻接矩阵:',adj_mat)

#可视化
ni,nj = np.nonzero(adj_mat)
plt.rc('font',size = 16),

pos=nx.shell_layout(G) #同心园
w = nx.get_edge_attributes(G,'capacity') #得到流量数据
nx.draw(G,pos,font_weight='bold',with_labels=True) #画图
nx.draw_networkx_edge_labels(G,pos,edge_labels=w) #边标签为流量

plt.show

```

## Busacker-Gowan 算法：
![[Pasted image 20260613165136.png]]


1. 先不管流量，找到一条权重和（费用）最小的路径
2. 在此之上，有最大流量等于这条路上最小的容量那条边
3. 添加反向边，尝试其他路径
4. 等到流量和达到目标，就停止

## 例子

![[Pasted image 20260613171252.png]]

利用`maxFlow = nx.max_flow_min_cost(G,起点，终点)`
得到最大流信息，是一个字典，记录每条边流经的流量信息
利用`maxcost=nx.cost_of_flow(G,maxFlow)`
得到最小费用信息

```python
import numpy as np
import networkx as nx

L = [ ('vs', 'v2', 5, 3), ('vs', 'v3', 3, 6), ('v2', 'v4', 2, 8), ('v3', 'v2', 1, 2), ('v3', 'v5', 4, 2), ('v4', 'v3', 1, 1), ('v4', 'v5', 3, 4), ('v4', 'vt', 2, 10), ('v5', 'vt', 5, 2)]
G=nx.DiGraph()
for k in range(len(L)):
	G.add_edge(L[k][0],L[k][1],capacity=L[k][2],weight=L[k][3])

maxFlow=nx.max_flow_min_cost(G,'vs','vt')
print('最大流为：', maxFlow)

mincost=nx.cost_of_flow(G,maxFlow)
print('最小费用为：',mincost)

node=list(G.nodes()) #通过边来提取顶点
n = len(node)
flow_mat=np.zeros((n,n))
for i,adj in maxFlow.items():
	for j,f in adj.items():
		flow_mat[node.index(i),node.index(j)]=f 

print('最大流的流量为：', sum(flow_mat[:,-1]))
print('最小费用最大流的邻接矩阵为：\n',flow_mat)

```
