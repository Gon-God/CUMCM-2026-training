# 无向图与有向图

**无向图G**: 由**非空顶点集V**和**边集E**构成的连接结构
记为：G(V, E)

- V中的元素称为G的顶点
- E中的元素称为G的边

- |V|是G中顶点的个数
- |E|表示G中边的个数

- G中的每条边是连接两个顶点的**线**，记为**ek(vi, vj)**
   vi,vj为顶点

- 对于**无向图**来说，**边是无方向**的，即ek(vi, vj) = ek(vj, vi)

- 有公共端点的两条边，称为**邻边**。比如：三角形任意两条边都有公共端点，所以他们都是邻边。

-  带方向的边称为**有向边**，或者**弧**，如果每一条边都有方向，就是有向图

**有向图**：记为**D(V, A)**, V为**顶点集**，A为**弧集合**。

- 弧ak(vi, vj)的方向是**vi指向vj**， vi称为**始端**，vj称为**末端**或者**终端**。
- ak称为vi的**出弧**，vj的**入弧**

- 称G为有向图D的**基本图**，D为G的**定向图**

# 简单图，完全图，赋权图

- **环**：同一条边两个端点是同一顶点
- **重边/平行边**：两条边或多条边的端点是统一顶点，称这些边为**重边/平行边**
- **孤立点**：无任何边关联的顶点

- **简单图**：无环无重边的图
- **完全图**：任意两个顶点都相邻的**简单图**
- [**赋权图**](赋权图)：每一条边e都附有一个实数w(e)，记为G(V, E, W)

# 顶点的度

- 在**无向图**中，与顶点v关联的**边的数目**（环算两次）称为v的**度**，记d(v)
- 在**有向图**中，由顶点v**引出的弧的数目**为v的**出度**，记$d^+ (v)$
- 在**有向图**中，从顶点v**引入的弧的数目**为v的**入度**，记$d^- (v)$
- $d(v)= d^+ (v)+d^- (v)$ 称为v的**度**

- 度为**奇数**的点称为**奇顶点**，度为**偶数**的点称为**偶顶点**
