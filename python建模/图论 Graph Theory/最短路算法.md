# Dijkstra算法

**固定起点找最短路问题**

![[Pasted image 20260611214803.png]]

基本思路：按固定起点u0由近到远为顺序，依次求得u0到图G各顶点的最短路和距离，直到顶点v0


### 引入三个辅助工具

1. **`l(v)`** – 顶点 `v` 的“当前最短路径长度估计”。  
    初始时：`l(u0)=0`，其它点 `l(v)=∞`。  
    随着算法进行，`l(v)` 会不断减小，直到变成真正的**最短距离**（此时称为 P 标号，永久标号）。
    
2. **`z(v)`** – 顶点 `v` 的“父顶点”，即当前找到的最短路径上，`v` 的**前一个顶点**。  
    例如 `z(v)=u` 意味着从 `u0` 到 `v` 的当前最短路径中，最后一个经过的顶点是 `u`（因此路径末尾是 `u → v`）。  
    初始时：所有 `v ≠ u0` 的 `z(v) = u0`，意思是一开始认为它们都直接和起点相连（虽然距离是无穷大，只是占位）。
    
3. **`S_i`** – 到第 i 步时，已经**确定永久标号（P标号）**的顶点集合。  
    P标号表示该顶点的 `l(v)` 已经等于真实的**最短距离**，不会再被更新。  
    初始 `S0 = {u0}`，即起点最先被确定为永久。
    
理解：
     4
  (1)----(2)
  |   \      |
 2|    \3  |1
  |       \   |
(3)----(4)
	5


**从节点 1 出发：**

- 初始：dist[1]=0, dist[2]=∞, dist[3]=∞, dist[4]=∞
    
- 选择节点1：更新邻居 → dist[2]=4, dist[3]=2, dist[4]=3
    
- 选择当前最短未处理节点3（距离2）：更新邻居 → 通过3到4：2+5=7 > 当前3，不更新；到2：2+? 无直接边
    
- 选择节点4（距离3）：更新邻居 → 通过4到2：3+1=4，与现有dist[2]=4相同，不更新
    
- 选择节点2（距离4）：无更优更新
    
- 最终最短距离：1→2:4，1→3:2，1→4:3

**例子**：v1到v8的最短路径
![[Pasted image 20260611220210.png]]


```python
import networkx as nx

G = nx.DiGraph()
List = []
G.add_nodes_from(range(1,10))
G.add_weighted_edges_from(List)

path = nx.dijkstra_path(G,1,8,weight='weight')#求最短路径
d = nx.dijkstra_path_length(G,1,8,weight ='weight')#求最小长度

print('最小路径为:',path)
print('最小费用为:',d)
```

# Floyd算法

求所有顶点之间最短路，
与Dijkstra不同，这里的起点不是固定的。

初始化：
![[Pasted image 20260611221424.png]]

基本思想：递推产生一个矩阵序列Ak,aij表示顶点vi到vj的路径所经过的顶点序号不大于k的最短路径长度
用迭代算法，得到下一个A,
![[Pasted image 20260611221758.png]]
计算A,得到的An就是各个顶点之间的最短距离值

需要引入一个Rk来记录最短路径
![[Pasted image 20260611222043.png]]



计算：
![[Pasted image 20260611222313.png|697]]

例子：
![[Pasted image 20260611222615.png]]
```python
G=nx.Graph()
List = [(1,3,10),(1,4,60),(2,4,20),(2,3,5),(3,4,1)]

G.add_nodes_from(range(1,5))
G.add_weighted_edges_from(List)
d = nx.floyd_warshall_numpy(G) #最短距离矩阵
print(d)

path = nx.shortest_path(G, weight= 'weight', method = 'belman-ford') #求最短路径
for i in range(1, len(d)):
	for j in range(1+1, len(d)+1):
		print(path[i][j]) #从i到j的最短路径

```
