
**因子分析**是一种多元统计方法，它的核心逻辑是：**利用少数几个不可观测的潜在变量（因子），去解释众多可观测的原始变量之间的相关性**。

因子分析将原始变量分解为若干个因子的线性组合
![[Pasted image 20260617104606.png]]


### 、 标准分析流程

无论在哪种软件中操作，因子分析都遵循以下核心步骤[](https://cloud.tencent.cn/developer/information/python%E8%BF%9B%E8%A1%8C%E5%9B%A0%E5%AD%90%E5%88%86%E6%9E%90)：

1. **数据预处理与标准化**：如果不同变量的量纲（单位）差异很大（例如，一个变量是“元”，另一个是“公斤”），通常需要对数据进行标准化处理，以消除量纲影响[](https://www.e-com-net.com/article/1712363815267545088.htm)。
    
2. **适用性检验**：这是非常关键的一步，用于判断你的数据是否适合做因子分析。
    
    - **KMO检验**：检验变量间的偏相关性。KMO值越接近1，说明变量间的共同因素越多，越适合做因子分析。**一般要求KMO值大于0.6，严格的标准是大于0.7**[](https://cloud.tencent.cn/developer/information/python%E8%BF%9B%E8%A1%8C%E5%9B%A0%E5%AD%90%E5%88%86%E6%9E%90)[](https://www.e-com-net.com/article/1712363815267545088.htm)。
        
    - **Bartlett球形检验**：检验变量间是否相互独立（即相关系数矩阵是否为单位阵）。如果检验的**p值小于0.05（或更严格的0.01）**，则拒绝原假设，说明变量间存在相关性，适合做因子分析[](https://www.e-com-net.com/article/1712363815267545088.htm)。
        
3. **提取因子**：这是分析的核心。你需要确定要提取多少个公共因子（潜在变量）。常用方法包括：
    
    - **根据特征值**：提取特征值大于1的因子[](https://cloud.tencent.cn/developer/information/python%E8%BF%9B%E8%A1%8C%E5%9B%A0%E5%AD%90%E5%88%86%E6%9E%90)。
        
    - **根据累积方差贡献率**：提取的因子累计解释的方差比例达到一个可接受的水平（如60%或70%以上）[](https://www.e-com-net.com/article/1712363815267545088.htm)。
        
    - **参考碎石图**：观察碎石图中特征值曲线的“拐点”，拐点之后的因子可以舍弃[](https://www.e-com-net.com/article/1712363815267545088.htm)。
        
4. **因子旋转**：旋转的目的是让因子载荷矩阵的结构更简单、更易于解释。它能让每个原始变量在少数几个因子上的载荷很高，而在其他因子上的载荷很低[](https://cloud.tencent.cn/developer/information/python%E8%BF%9B%E8%A1%8C%E5%9B%A0%E5%AD%90%E5%88%86%E6%9E%90)。最常用的方法是**最大方差法**[](https://xiazai.zol.com.cn/jiqiao/337623.html)。
    
5. **解释与命名**：根据旋转后的因子载荷矩阵，观察每个因子主要解释了哪些原始变量，然后为这些因子赋予有实际意义的名称[](https://www.e-com-net.com/article/1712363815267545088.htm)。
    
6. **计算因子得分**：如果需要，可以计算每个样本在每个因子上的得分，用于后续的回归、聚类等分析[](https://www.e-com-net.com/article/1712363815267545088.htm)。

利用`factor_analyzer`库

```python
import pandas as pd

import numpy as np

import matplotlib.pyplot as plt

  

# 核心库：因子分析

from factor_analyzer import FactorAnalyzer

# 检验模块

from factor_analyzer.factor_analyzer import calculate_kmo, calculate_bartlett_sphericity

  

# 可选：用于加载示例数据

from sklearn.datasets import load_iris

from sklearn.preprocessing import StandardScaler

  
  

# 加载数据

iris = load_iris()

df = pd.DataFrame(iris.data, columns=iris.feature_names)

  

# 标准化数据

scaler = StandardScaler()

df_scaled = pd.DataFrame(scaler.fit_transform(df), columns=df.columns)

  

print(df_scaled.head())

  

# 计算KMO值

kmo_all, kmo_model = calculate_kmo(df_scaled)

print(f"KMO检验值: {kmo_model:.4f}")  # 通常要求 > 0.6

  

# 计算Bartlett球形检验

chi2, p_value = calculate_bartlett_sphericity(df_scaled)

print(f"Bartlett球形检验p值: {p_value:.10f}") # 要求 p < 0.05
```

![[Pasted image 20260617111401.png]]

如果两个检验都满足要求，则进行因子分析

```python
# 先不指定旋转，进行初步分析以获取特征值

fa = FactorAnalyzer(rotation=None)

fa.fit(df_scaled)

  

# 获取特征值

ev, v = fa.get_eigenvalues()

  

# 打印特征值

print("特征值:", ev)

  

# 绘制碎石图

plt.scatter(range(1, df_scaled.shape[1]+1), ev)

plt.plot(range(1, df_scaled.shape[1]+1), ev)

plt.title('Scree Plot')

plt.xlabel('Factors')

plt.ylabel('Eigenvalue')

plt.grid()

plt.show()
```

### 5. 执行因子分析并旋转

确定因子个数后，就可以正式建立模型。为了结果更易解释，通常会进行**因子旋转**。最常用的是**方差最大化正交旋转（Varimax）**

```python
# 设定因子个数为2，并使用varimax旋转

n_factors = 2

fa = FactorAnalyzer(n_factors=n_factors, rotation='varimax')

fa.fit(df_scaled)

  

# 获取旋转后的因子载荷矩阵

loadings = fa.loadings_

print("因子载荷矩阵:\n", loadings)
```

因子载荷矩阵: [[ 0.90120548 0.01789008] [-0.15041281 0.98619517] [ 0.96415345 -0.28461929] [ 0.92140125 -0.23324486]]

### 6. 结果解读与命名

**因子载荷矩阵**是解读的核心。它表示每个原始变量与公共因子之间的相关系数。通常，载荷绝对值 > 0.4或0.5的变量被认为与对应因子密切相关。

**示例解读**（Iris数据集）：  
假设输出的载荷矩阵如下：

|变量|因子1|因子2|
|---|---|---|
|花萼长度 (sepal length)|**0.88**|0.18|
|花萼宽度 (sepal width)|0.10|**0.99**|
|花瓣长度 (petal length)|**0.98**|0.07|
|花瓣宽度 (petal width)|**0.96**|0.10|

- **因子1** 在“花萼长度”、“花瓣长度”和“花瓣宽度”上有很高的正载荷，可以命名为 **“花瓣形态因子”**。
    
- **因子2** 仅在“花萼宽度”上载荷很高，可以命名为 **“花萼宽度因子”**。
