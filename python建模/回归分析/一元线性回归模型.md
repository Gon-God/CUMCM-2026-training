.summary()函数输出值如下：

- **因变量名称、模型类型、拟合方法**
    
- **回归系数**：估计值、标准误、t 统计量、p 值、95% 置信区间
    
- **拟合优度指标**：R-squared（决定系数）、Adjusted R-squared（调整后决定系数）
    
- **整体显著性**：F 统计量及其 p 值
    
- **残差相关统计**：对数似然、AIC、BIC 等
    
- **诊断统计**：如 Durbin-Watson 统计量（检验自相关）、Jarque-Bera 检验（正态性）等

.outlier_test()返回异常值的函数
.mse_resid返回残差平方
.get_prediction(d)
.summary_frame(alpha=0.95)返回一个DataFrame,alpha为置信水平
包含以下数据

| `mean`          | 预测均值（点预测值）          |
| --------------- | ------------------- |
| `mean_se`       | 预测均值的标准误            |
| `mean_ci_lower` | 预测均值的置信区间下限（默认 95%） |
| `mean_ci_upper` | 预测均值的置信区间上限         |
| `obs_ci_lower`  | 新观测值的预测区间下限（包含残差变异） |
| `obs_ci_upper`  | 新观测值的预测区间上限         |

```python
import numpy as np
import statsmodeks.api as sm
import pylab as plt

def check(d): #输入一个数据d
	x = d[0]
	y = d[1]
	d = {'x':x,'y':y}
	re = sm.formula.ols('y~x',d).fit()
	print(re.summary()) #
	print(re.outlier_test())
	print('残差的方差：',re.mse_resid)
	pre=re.get_prediction(d)
	df = pre.summary_frame(alpha=0.05)
	dfv=df.values
	low,upp = dfv[:,4:].T
	r = (upp-low)/2
	num = np.arange(1,len(x)+1)
	plt.errorbar(num,re.resid,r,fmt='o')
	plt.show()
	

data = np.array([[0.10, 0.11, 0.12, 0.13, 0.14, 0.15, 0.16, 0.17, 0.18, 0.20, 0.22, 0.24],
                 [42.0, 42.5, 45.0, 45.5, 45.0, 47.5, 49.0, 51.0, 50.0, 55.0, 57.5, 59.5]])

check(data)
```
