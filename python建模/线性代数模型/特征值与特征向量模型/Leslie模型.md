
这个模型的核心思想是**将种群按年龄（或发育阶段）分组**，通过一个数学矩阵来描述不同年龄组个体随时间的演变过程

用于预测下一时间段每一年龄组的人口数量

### 模型的核心结构

Leslie模型通过两个关键部分来运作：

1. **Leslie矩阵 (L)**：这是一个方阵，它封装了种群在不同年龄组间的转换规律。其结构非常特殊，大部分元素为零，只有第一行和次对角线有非零值。
    
    - **第一行**：代表各个年龄组的**生育系数（繁殖力）**
        
    - **次对角线**：代表各个年龄组的**存活系数
    - 例如：
		L = | a1   a2  a3  a4 |
		   | b1   0     0    0 |
           | 0     b2   0    0 |
           | 0      0    b3  0 |
2. **年龄分布向量 (N(t))**：这是一个列向量，表示在时间 `t`，**各个年龄组的人口数量。**
    

**模型的动态过程**可以用一个简洁的线性方程表示：  
**N(t+1) = L · N(t)**  
其中：

- `N(t)` 是当前时刻的年龄结构向量。
    
- `L` 是Leslie矩阵。
    
- `N(t+1)` 是下一时刻的年龄结构预测值。
    

通过这个公式，可以迭代计算出未来多个时间点的种群年龄结构和总人口数量。

### 例子：
三个年龄组(0, 5], (5, 10], (10,15]
a1=0, a2=4, a3=3
b1=0.5, b2=0.25
$L=[(0,4,3), (0.5,0,0), (0,0.25,0)]$

   H(t) = [500, 1000, 500]
   经过运算就可得到H(t+1)
- `N₀(t+1) = 2·N₁(t) + 1.5·N₂(t)`
    
- `N₁(t+1) = 0.4·N₀(t)`
    
- `N₂(t+1) = 0.3·N₁(t)`
    
- `N₃(t+1) = 0.1·N₂(t)`
