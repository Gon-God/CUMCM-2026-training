# 秩和比法



### 核心概念：什么是“秩”？

“秩”就是**排名**。秩和比法正是通过将原始数据转化为秩次，来消除不同指标量纲的影响。

- **正向指标（值越大越好）**：如治愈率、销售额，按数值**从小到大**排秩，最小值秩为1，最大值秩为n[](https://blog.csdn.net/AZZZZ1111/article/details/149788618)。
    
- **逆向指标（值越小越好）**：如发病率、投诉率，按数值**从大到小**排秩，最大值秩为1，最小值秩为n[](https://blog.csdn.net/AZZZZ1111/article/details/149788618)。

计算：
1. 对指标内部数据进行排序，正向的由大到小，负向的由小到大
2. 计算秩和比（RSR）
	![[Pasted image 20260617183245.png]]
3.对秩和比排序。越大越好
