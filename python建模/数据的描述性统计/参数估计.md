
利用样本对总体进行统计推断

主要有点估计与区间估计，其中点估计有矩估计和极大似然估计方法

#### （1）点估计

直接用样本计算出的一个数值，去估计总体的未知参数。

- **例子**：随机抽1000个中国成年男性，测得平均身高为170.2cm。我们就用 **170.2cm** 这个**点**去估计全国成年男性的平均身高。
    
- **优点**：给出一个明确的数值。
    
- **缺点**：没有给出这个估计值的可信程度或可能误差。它恰好等于真值的概率几乎为零。
#### （2）区间估计

给出一个可能的范围（区间），并说明这个区间包含总体真值的可靠程度（置信水平）。

- **例子**：根据样本数据，我们有 **95%的把握** 认为，全国成年男性的平均身高在 **169.5cm 到 170.9cm 之间**。
    
    - **[169.5cm, 170.9cm]** 就是**置信区间**。
        
    - **95%** 就是**置信水平**（或置信度）。
        
- **优点**：提供了估计的精度和不确定性信息，更科学、更实用。

### 3. 常见的估计方法

统计学家发展了几种方法来计算出好的估计量，最常用的有：

- **矩估计法**：思想简单，用样本的均值、方差等“矩”去对应总体的矩，解出参数。
    
- **最大似然估计**：最主流的方法。其核心思想是：找到一个参数值，使得当前得到的这组样本数据出现的概率最大。（“已经发生了的事件，在它发生的条件下最合理”）
    
- **最小二乘估计**：在回归分析中常用，目标是让模型预测值与实际观测值之间的误差平方和最小。
    

### 4. 如何评价一个估计好不好？

一个好的估计量通常需要满足三个基本标准：

- **无偏性**：估计量的期望值等于总体参数的真值。意思是没有系统性偏差，多次抽样的平均结果会击中目标。
    
- **有效性**：在多个无偏估计量中，方差越小越有效。意味着估计量波动小，更稳定、更精确。
    
- **一致性**：样本量越大，估计量越接近总体真值。这是大样本下的理想性质。

## 1. 均值的置信区间（正态分布 / t 分布）


当样本量较小且总体方差未知时，使用 **t 分布**（更稳健）。

套用代码即可
```python
import numpy as np
from scipy import stats

# 样本数据
data = [12.3, 13.1, 11.9, 12.8, 13.0, 12.5, 13.2, 12.7, 12.9, 13.4]

# 计算基本统计量
n = len(data)
mean = np.mean(data)
std_err = stats.sem(data)          # 标准误 = 样本标准差 / sqrt(n)
confidence_level = 0.95
alpha = 1 - confidence_level

# 使用 t 分布（适用于小样本，总体方差未知）
t_critical = stats.t.ppf(1 - alpha/2, df=n-1)   # 临界值
margin_error = t_critical * std_err
ci_t = (mean - margin_error, mean + margin_error)

print(f"均值: {mean:.4f}")
print(f"95% 置信区间 (t分布): {ci_t}")
```

当样本量较大（通常 n ≥ 30）或总体方差已知时，使用 **正态分布**；  

```python
import numpy as np
from scipy import stats

data = np.random.normal(50, 10, 100)   # 生成100个样本
mean = np.mean(data)
se = np.std(data, ddof=1) / np.sqrt(len(data))
z_crit = stats.norm.ppf(0.975)          # 95% 置信区间对应 1.96
ci = (mean - z_crit * se, mean + z_crit * se)
print(ci)

# 或者直接使用 stats.norm.interval，但需要知道总体标准差
# stats.norm.interval(0.95, loc=mean, scale=se)   # 这里 se 是标准误
```
