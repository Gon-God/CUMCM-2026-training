# 频数表与直方图

将数据取值划分为几个区间，根据数据出现的次数描出次数，为频数。以此得到频数表

以数据取值为横坐标，频数为纵坐标的称为直方图

**绘制**：

利用`plt.hist(一维数组或列表，bins = 分几个区间, range=(数组取值范围), density=False, color = '', alpha=0.9)`
density是表示概率密度还是频率
alpha是透明度


例如：
```python
import pandas as pd
import pylab as plt

df = df.T
plt.subplot(121)
h1 = plt.hist(df[0],5)
plt.subplot(122)
plt.hist(df[1],5)

plt.show() 
```

# 经验分布函数

根据样本数据构造的**累计分布函数**的估计。它刻画了样本中**小于等于某个值 xx 的数据点所占的比例**。

即利用顺序统计量除n构建的函数

![[Pasted image 20260614155041.png]]

### 绘制：

先要通过顺序和公式计算出y经验分布函数和x的顺序
再用`plt.step(x_sorted, y_ecdf, where='post')`绘制

例子：
```python
import numpy as np
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei'] #正常显示中文标签
plt.rcParams['axes.unicode_minus'] = False #用来正常显示负号

# 生成示例数据（正态分布）
np.random.seed(42)
data = np.random.normal(loc=0, scale=1, size=100)
#随机100个数据

# 计算经验分布函数
x_sorted = np.sort(data)                 # 顺序统计量，将数据按顺序排放
y_ecdf = np.arange(1, len(data)+1) / len(data)   # 累计比例，公式

# 绘制阶梯图
plt.step(x_sorted, y_ecdf, where='post', label='经验分布函数 (ECDF)')
plt.xlabel('x')
plt.ylabel('F_n(x)')
plt.title('经验分布函数图')
plt.grid(alpha=0.3)
plt.legend()
plt.show()
```

# Q-Q图

Quantile-quantile Plot 的简称，用于检验**拟合优度**

![[Pasted image 20260614160239.png]]

### 1. 基本原理

- **分位数**：将一组数据从小到大排序后，某个百分比位置上的数值。比如中位数就是50%分位数。
    
- **Q-Q图的构造**：把待检验数据的每个分位数作为Y轴，把理论分布（或另一组数据）的对应分位数作为X轴，绘制散点图。
    
- **结果判断**：
    
    - **点在一条直线附近** → 两个分布相似（数据符合该理论分布）。
        
    - **点明显偏离直线** → 两个分布不同。
        

### 2. 最常见的用途：检验正态性

在数据分析中，Q-Q图最常用于**判断一组数据是否近似服从正态分布**。做法是画出一个“正态Q-Q图”：

- X轴：理论正态分布的分位数
    
- Y轴：样本数据的分位数


绘图：
利用`stats.probplot(data, dist="norm", plot=plt)`
data: 样本数据
dist="norm"：指定理论分布为正态分布
plot=plt：让绘图结果直接显示

例如：
```python
import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

# 生成数据
np.random.seed(42)
data = np.random.normal(loc=0, scale=1, size=1000)

# probplot 的三个关键参数：
# data: 样本数据
# dist="norm"：指定理论分布为正态分布
# plot=plt：让绘图结果直接显示
stats.probplot(data, dist="norm", plot=plt)

plt.title("Q-Q Plot using scipy.stats.probplot")
plt.grid(True)
plt.show()
```
