简便代码：
用`scipy.stats.f_oneway()`

```python
import scipy.stats as stats

# 示例数据：三个组别的测量值
group1 = [2.3, 2.5, 2.7, 2.4, 2.6]
group2 = [3.1, 3.3, 3.0, 3.2, 3.4]
group3 = [4.0, 4.2, 3.9, 4.1, 4.3]

# 执行单因素方差分析
f_stat, p_value = stats.f_oneway(group1, group2, group3)

print(f"F统计量: {f_stat:.4f}")
print(f"P值: {p_value:.4f}")

# 根据p值判断显著性（通常alpha=0.05）
alpha = 0.05
if p_value < alpha:
    print("拒绝原假设：至少有两组均值存在显著差异")
else:
    print("不能拒绝原假设：各组均值之间无显著差异")
```

输出表格：
```python
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols

# 准备长格式数据
data = pd.DataFrame({
    'value': [2.3, 2.5, 2.7, 2.4, 2.6,
              3.1, 3.3, 3.0, 3.2, 3.4,
              4.0, 4.2, 3.9, 4.1, 4.3],
    'group': ['A']*5 + ['B']*5 + ['C']*5
})

# 拟合OLS模型
model = ols('value ~ C(group)', data=data).fit()
# 执行方差分析
anova_table = sm.stats.anova_lm(model, typ=2)

print(anova_table)
```

A与B是影响因素，对X是一个三维的表格

1. 无交互影响的A,B因素

分别检验A和B对事件的影响即可
![[Pasted image 20260615133449.png]]


例子：

```python
import statsmodels.api as sm
from statsmodels.formula.api import ols
import pandas as pd
import numpy as np

# 示例数据：研究肥料（A/B）和土壤类型（X/Y/Z）对作物产量的影响
data = pd.DataFrame({
    'yields': [25, 27, 26, 28, 30, 32, 31, 33, 35, 37, 34, 36,
              29, 31, 30, 32, 33, 35, 34, 36, 38, 40, 39, 41],
    'fertilizer': ['A']*12 + ['B']*12,
    'soil': ['X']*4 + ['Y']*4 + ['Z']*4 + ['X']*4 + ['Y']*4 + ['Z']*4
})
print(data.head())


# 模型公式：Yield ~ Fertilizer + Variety
model = ols('yields ~ C(fertilizer) + C(soil)', data=data).fit()
anova_table = sm.stats.anova_lm(model, typ=2)  # Type II 平方和
print(anova_table)
```

2. 有交互影响的A,B因素

要加上交互效应的F值
模型中加入两个因子的交互项：`Yield ~ Fertilizer * Variety` 等价于 `Fertilizer + Variety + Fertilizer:Variety`

即`sm.stats.anova_lm(model_int, typ=2)` model 加上一个_int

```python
import statsmodels.api as sm
from statsmodels.formula.api import ols
import pandas as pd
import numpy as np

# 示例数据：研究肥料（A/B）和土壤类型（X/Y/Z）对作物产量的影响
data = pd.DataFrame({
    'yields': [25, 27, 26, 28, 30, 32, 31, 33, 35, 37, 34, 36,
              29, 31, 30, 32, 33, 35, 34, 36, 38, 40, 39, 41],
    'fertilizer': ['A']*12 + ['B']*12,
    'soil': ['X']*4 + ['Y']*4 + ['Z']*4 + ['X']*4 + ['Y']*4 + ['Z']*4
 
print(data.head())

model_int = ols('yields ~ C(fertilizer) * C(soil)', data=data).fit()
anova_table_int = sm.stats.anova_lm(model_int, typ=2)
print(anova_table_int)
```

3. 主效应：当某一个单因素有显著影响，称为有主效应
4. 当交互作用显著时候，主效应不可直接解释，要进行简单的效应分析。
5. 如果**交互作用显著**，则需要比较一个因子在另一个因子各个水平上的简单主效应（Simple main effects）。
