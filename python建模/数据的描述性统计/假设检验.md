
# 参数假设检验

总体分布函数形式已知，但其中含有未知参数。
为了推断总体的某些性质，我们做假设，然后判断是否成立

1. 单个总体均值的假设检验

正态总体均值未知，标准差已知：

![[Pasted image 20260614163127.png]]![[Pasted image 20260614163336.png]]

`statsmodels.stats.weightstats.ztest()` 是一个用来检验总体均值**假设**的函数。无论你是想验证某个样本的均值是否等于特定值（单样本），还是想比较两个独立样本的均值是否存在显著差异（双样本），只要满足Z检验的使用条件（通常是大样本或已知总体标准差），都可以用它来完成

`ztest(x1, x2=None, value=0)`

| 参数名           | 含义              | 说明                                                                                                                                                                                                                                                 |
| ------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x1`          | **第一组样本数据**     | 必需。可以是一个列表或NumPy数组。                                                                                                                                                                                                                                |
| `x2`          | **第二组样本数据**     | 可选。进行**双样本Z检验**时，必须提供该参数。                                                                                                                                                                                                                          |
| `value`       | **原假设中的均值或均值差** | 可选，默认为`0`。在**单样本检验**中，它代表你假定的总体均值μ₀；在**双样本检验**中，它代表两组总体均值之差的假定值μ₁-μ₂[](https://www.statsmodels.org/stable/generated/statsmodels.stats.weightstats.ztest.html)。                                                                                     |
| `alternative` | **备择假设的方向**     | 可选，默认为`'two-sided'`。你可以设置为以下选项：  <br>- `'two-sided'`: 均值不等于value (双侧检验)  <br>- `'larger'`: 均值**大于**value (单侧检验)  <br>- `'smaller'`: 均值**小于**value (单侧检验)[](https://www.statsmodels.org/stable/generated/statsmodels.stats.weightstats.ztest.html)。 |
| `usevar`      | **方差假设**        | 可选，默认为`'pooled'`。仅在**双样本检验**中有效，它告诉函数如何计算标准误差：  <br>- `'pooled'`: 假设两样本总体方差相等（合并方差）  <br>- `'unequal'`: 假设两样本总体方差不等（Welch's t-test近似）[](https://www.statsmodels.org/v0.14.4/generated/statsmodels.stats.weightstats.ztest.html)。                   |
| `ddof`        | **自由度修正**       | 可选，默认为`1.0`。用于修正标准差计算时的自由度，在Z检验中通常使用默认值即可[](https://docs.w3cub.com/statsmodels/generated/statsmodels.stats.weightstats.ztest)。                                                                                                                     |

返回值**第一个是z统计量（test statistic），第二个是p值（p-value）**

```python
import numpy as np
from statsmodels.stats.weightstats import ztest
from scipy.stats import norm

alpha = 0.05
sigma = 4.2

a = np.array([26.01,26.00,25.98,25.86,26.32,25.58,25.32,25.89,26.32,26.18])
l,p = ztest(a, value = 26) #l是默认的，标准差为1，所以必须要转化
xb.a.mean()
s=std(ddof=1)
z=l*s/sigma #套公式转换，z服从标准正态分布
za.norm.ppf(1-alpha/2, 0, 1) #
print('z统计量为：'，z)
print('p值:',p)
print('分位数：',za)


```

2. 已知均值，未知标准差的t检验法
`scipy.stats.ttest_1samp()`提供了t检验的方法

`scipy.stats.ttest_1samp(a, popmean, axis=0, nan_policy='propagate', alternative='two-sided')`

## 主要参数

- **`a`** : array_like  
    观测样本数据（一维或类似数组）。
    
- **`popmean`** : float  
    要比较的理论总体均值（原假设中的均值）。
    
- **`axis`** : int, optional  
    沿哪个轴进行检验（默认 0）。
    
- **`nan_policy`** : {‘propagate’, ‘raise’, ‘omit’}  
    处理缺失值（NaN）的方式。
    
- **`alternative`** : {‘two-sided’, ‘less’, ‘greater’} (SciPy 1.6.0+ 新增)  
    备择假设的类型：
    
    - `'two-sided'`：均值不等于 `popmean`（默认）
        
    - `'less'`：均值小于 `popmean`
        
    - `'greater'`：均值大于 `popmean`



![[Pasted image 20260615122051.png]]

```python
import numpy as np
from scipy.stats import t
from scipy.stats import ttest_1samp

data = np.array([159, 280, 101, 212, 224, 379, 179, 264,222, 362, 168, 250, 149, 260, 485, 170])
n = len(data)
ta = t.ppf(0.95,n-1) #t检验服从n-1个自由度的t分布
t_stat, p_two_sided = ttest_1samp(data, 225)
# 右侧检验的 p 值
p_right = p_two_sided / 2 if t_stat > 0 else 1 - p_two_sided / 2
print(f't 统计量值: {t_stat}')
print(f'右侧 p 值: {p_right}')
print('分位数：',ta)```

3. 两个正态总体均值差的t检验
![[Pasted image 20260615124814.png]]

![[Pasted image 20260615125025.png]]

利用
scipy.stats.ttest_ind()

```python
import numpy as np
from scipy import stats
# 两个正态分布样本（示例）
np.random.seed(42)
sample1 = np.random.normal(loc=100, scale=15, size=30)
sample2 = np.random.normal(loc=105, scale=15, size=30)

# 1. 等方差 t 检验
t_stat_equal, p_equal = stats.ttest_ind(sample1, sample2, equal_var=True)
print("等方差 t 检验：")
print(f"t 统计量 = {t_stat_equal:.4f}, p 值 = {p_equal:.4f}")

# 2. 方差不齐 Welch 检验
t_stat_welch, p_welch = stats.ttest_ind(sample1, sample2, equal_var=False)
print("\nWelch 检验：")
print(f"t 统计量 = {t_stat_welch:.4f}, p 值 = {p_welch:.4f}")
```
等方差 t 检验：
t 统计量 = -1.6932, p 值 = 0.0958

Welch 检验：
