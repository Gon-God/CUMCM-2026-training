判别分析要求有一定的先验信息，在已知若干类的情况下根据某种基准来建立判别式
从而对一个新的对象归类


**距离判别**法即计算各类的重心的均值。给定一个样品，如果其离i的重心最近，就认为其来自i类。

### 具体实现步骤（以两类分类为例）

假设我们有总体 G1 和 G2​，数据包含 p 个特征变量。

#### 第一步：计算各类别的“重心”（均值向量）

分别计算两类训练样本的均值：
μ1​=(xˉ11​,xˉ12​,...,xˉ1p​)T,μ2​=(xˉ21​,xˉ22​,...,xˉ2p​)T

#### 第二步：计算协方差矩阵

这里分两种情况，决定了分类边界的形状：

- **情况A（常见默认）**：假设两类协方差矩阵相同（Σ1=Σ2=Σ），则计算**联合协方差矩阵**（合并样本协方差）Σ。
    
- **情况B**：若协方差不等，则分别计算各类的协方差矩阵 Σ1 和 Σ2
#### 第三步：计算马氏距离

对于任意一个新样本 X=(x1,x2,...,xp)T，计算它到两个总体重心的马氏距离平方：

_(注：如果使用联合协方差，则 Σ1−1 和 Σ2−1Σ替换为同一个 Σ−1)_

#### 第四步：判别准则（比较大小）

- 如果 D12(X)<D22(X)，则判定 X∈G1；
    
- 如果 D12​(X)>D22​(X)，则判定 X∈G2；
    
- 如果相等，则暂缓判断或归入任意一类（通常需要结合先验概率）。



实现：协方差相等的情况：
```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score


# 1. 准备数据
iris = load_iris() #一个数据集
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 2. 创建并训练LDA模型
lda = LinearDiscriminantAnalysis()
lda.fit(X_train, y_train)

# 3. 进行预测
y_pred = lda.predict(X_test)

# 4. 评估
print(f"LDA准确率: {accuracy_score(y_test, y_pred):.4f}")
```
LDA准确率: 1.0000
