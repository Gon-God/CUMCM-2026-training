
对于一个函数f(x)已有互不相同的观测点x，找一条曲线$\phi(x)$，经过所有的观测点。


任意非观测点都用曲线估计

称此类建模问题为**插值问题**
寻找近似曲线的方程为**插值方法**

观察点x_i称为插值节点，f(x)称为被插函数或者原函数, $\phi(x)$称为插值函数。

含观察点x的最小区间称为插值区间，
$\hat{x}$为插值点，$\phi(\hat{x})$为插值

# 多项式插值

![[Pasted image 20260613185353.png]]

1. 把n个点转化为最高不超过n次方的多项式
2. 然后用这个多项式来表示现有的点
3. 范德蒙德行列式（Vandermonde）就是多项式的A
4. Ax=y,求得x,这里得到x的向量就是系数向量
5. 于是我们有$x=A^{-1}*y$
6. 当x0...xn都不相同时，说明这个多项式存在解，即nonsingular，解存在且唯一

插值余项：

![[Pasted image 20260613185818.png]]


`np.vander(向量)`提供了**生成范德蒙德矩阵**（Vandermonde matrix）的函数
例：![[Pasted image 20260613190411.png]]

```python
import numpy as np
import pylab as plt

x0 = np.arange(1,7)
y0 = np.array([16,18,21,17,15,12])

A = np.vander(x0) #生成范德蒙德行列式
p = np.linalg.inv(A) @ y0 #求得系数矩阵
yh = np.polyval(p, [1.5, 2.6]) #由多项式得到预测值

#绘图
plt.plot(x0, y0, 'o')               # 画原始数据点（圆点）
plt.plot(1.5,yh[0],'*')
plt.plot(2.6,yh[1],'**') #观测点
xt = np.linspace(1, 6, 100)         # 在1~6之间均匀取100个点
plt.plot(xt, np.polyval(p, xt))     # 画出插值多项式曲线
plt.show()
```

# 拉格朗日（Lagrange）插值方法

构造函数
![[Pasted image 20260613192409.png]]

即：
![[Pasted image 20260613192422.png]]

因为每个 l_i(x)只在 x_i​ 处为 1，其他地方为 0，那么：

- 让 l_0(x) 乘上 y0，它在 x0处贡献 y0​，在其他点贡献 0；
    
把它们加起来：

$L_n(x)=y_0l_0(x)+y_1l_1(x)+⋯+y_nl_n(x)$

当 x=xi时，只有第 i 项是 yi，其余项都是 0，所以 Ln(xi)=yi​，完美经过所有已知点。

于是有公式
![[Pasted image 20260613192709.png]]

这依然是一个最高为n次的多项式
依然用求系数的方式得到预测值

## 例子


`scipy.interpolate.lagrange(xi,yi)`提供了求拉格朗日多项式的系数

![[Pasted image 20260613190411.png]]

```python
import numpy as np
from scipy.interpolate import lagrange
import pylab as plt

x0 = np.arange(1,7)
y0 = np.array([16,18,21,17,15,12])
p = lagrange(x0,y0)

b = [1.5,2.6]
yh = np.polyval(p,b)


plt.plot(x0, y0, 'o')               # 画原始数据点（圆点）
plt.plot(b,yh,'*') #观测点
xt = np.linspace(1, 6, 100)         # 在1~6之间均匀取100个点
plt.plot(xt, np.polyval(p, xt))     # 画出插值多项式曲线
plt.show()
```

# 分段线性插值


**龙格震荡现象：**

高次插值计算复杂且不稳定。插值次数越高，数据点越多，插值结果反而越偏离原函数

**分段线性插值**

将每两个相邻的节点用直线连起来，形成的折线就是分段线性插值函数

![[Pasted image 20260613194822.png]]



![[Pasted image 20260613194844.png]]

用分段线性插值方法使用于有大量的数据点，能很好的消除误差
实际上在计算插值时候，只用到相邻两个点。大多情况下，观测点距离够小，误差就更小
必然概率分布表等等，就可以查表用离散的点来做线性插值得到近似概率

# 三次样条插值

样条：光滑的，有曲率的分段多项式为样条函数

三次样条插值即用三次函数将相邻两个点连起来
并且要求
1. **函数值相等**：曲线必须穿过所有已知点。
    
2. **一阶导数相等**：曲线在连接点处的切线方向相同，没有尖角。
    
3. **二阶导数相等**：曲线在连接点处的弯曲程度也相同，光滑过渡。

这个方法曲线非常平滑美观，并且误差也比较小
但是对异常数据敏感，且计算量大
