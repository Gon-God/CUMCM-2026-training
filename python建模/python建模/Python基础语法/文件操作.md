# 文件操作基础知识
### open()
打开指定文件
语法：
```python
open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None)
```

最常用的是前两个参数：`file`（文件路径）和 `mode`（打开模式）

| 模式 | 说明 |
| --- | --- |
| `'r'`|只读（默认）。文件必须存在。|
|`'w'`|只写。会**覆盖**原有内容，文件不存在则创建。|
|`'x'`|独占创建，写模式。文件已存在则报错。|
|`'a'`|追加。在文件末尾写入，不存在则创建。|
|`'b'`|二进制模式（如 `'rb'`, `'wb'`）。|
|`'t'`|文本模式（默认，如 `'rt'` 等同于 `'r'`）。|
|`'+'`|读写模式（如 `'r+'`, `'w+'`）。|
close()写入文件，同时关闭文件

实例：
```python
# 写入文本
f = open('test.txt', 'w', encoding='utf-8')
f.write('你好，世界')
f.close()

# 读取文本
f = open('test.txt', 'r', encoding='utf-8')
content = f.read()
print(content)   # 你好，世界
f.close()
```
### with
with用于自动释放资源
语法：
```python
with open('data.txt', 'r') as f:
    data = f.read()
# 离开 with 块时，文件自动关闭
```
