# 匿名函数

- 即**单行的**的函数
## 语法
```python
lambda 参数1,参数2 : expression

#example
f = lambda x,y,z: x*y*z 
L = lambda x: [x**2, x**3, x**4] (输出一个列表)

f(3,4,5)
L(2)
```

## 枚举
即输出所有可以迭代的对象，同时列出索引与数据本身
```python
语法：
enumerate(iterable, start=0)
start = 索引起始值

fruits = ["苹果", "香蕉", "橙子"]
for index, value in enumerate(fruits):
    print(index, value)
# 输出：
# 0 苹果
# 1 香蕉
# 2 橙子

for i, ch in enumerate("hello"):
    print(i, ch)
# 输出字符及其位置
```

## filter()函数
返回序列里面所有为True的值
可以用于各种过滤，重复值，特定值等等
要把它转为列表或者集合等等
```python
语法：
filter(function, iterable)

a = filter(lambda x: x>10, [1, 11 ,2])
--> list(a) = [11]

words = ["apple", "banana", "cherry", "date"]
long_words = filter(lambda w: len(w) > 5, words)
print(list(long_words))   # ['banana', 'cherry']
```

## zip()函数
把多个对象压缩为一个个对应索引的元组
长度不同的时候，按最短的截断
```python
语法：
zip(iterable1, iterable2, ...)

a = [1, 2, 3]
b = ['a', 'b', 'c']
c = [True, False, True]
result = list(zip(a, b, c))
print(result)
# [(1, 'a', True), (2, 'b', False), (3, 'c', True)]
```
解压函数：zip(*iterable)
```python
pairs = [('Alice', 85), ('Bob', 92), ('Charlie', 78)]
names, scores = zip(*pairs)
print(names)   # ('Alice', 'Bob', 'Charlie')
print(scores)  # (85, 92, 78)
```
