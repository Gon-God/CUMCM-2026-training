# 预处理

1. **无量纲化处理**：不同目标之间单位不同，无法比较和相加，除以某个参考值得到一个没有单位的纯数字
2. **数量级的归一化处理**：目标的值可能在完全不同的数值范围，比如0-0.1和0-1000。把数量级压缩到0-1的范围里面

# 理想点法

以每个单目标最优解为该目标的理想值，使每个目标函数值与理想差的加权评分和最小

1. 求每个目标函数的最优值
![[Pasted image 20260611111553.png]]
2. 构造每个目标与理想值的差的加权平方和，权重就是归一化处理
![[Pasted image 20260611111736.png]]
3. 求评价函数的最优值 ![[Pasted image 20260611111814.png]]

# 优先级法(序贯解法)

根据目标重要性分为不同优先级，先求优先级高的最优值，再求次高在此约束条件下的最优值，继续进行下去

1. 确定优先级
2. 求第一级单目标的最优值
3. 以第一级最优值为约束，求第二级最优值
