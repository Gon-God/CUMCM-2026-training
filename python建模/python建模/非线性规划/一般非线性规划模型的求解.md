
对于一般的非线性规划问题，不是凸规划，求解一般用
scipy.optimize.minimize()函数

## 例子：
![[Pasted image 20260611101908.png]]

```python
import numpy as np
from scipy.optimize import minimize

#初始化数值
c2 = np.array([[-1, 0.15], [-0.15, -2]]) #二次型
c1 = np.array([98,277]) #一维向量二次型
a = np.([1,1],[1,-1]) #约束条件的左边矩阵
b = np.([100,0]) #约束条件的右边向量

#具体函数条件
obj = lambda x: x @ c2 @ x +c1 @ x #目标函数的表示形式
con = {'type':'ineq', 'fun':lambda x: b-a@x} #约束函数的矩阵表达
#'type'是约束类型，'ineq'是不等式约束
bd = [(0, np.inf) for i in range(a.shape[1])] 
#这行代码是全大于0，范围是0到正无穷，a.shape[1]指的是矩阵的列数

#求解
res = minimize(obj, np.random.randn(2), constraints=con, bounds=bd)
#obj是目标函数，np.random.randn(2)是生成一个随机的初始的猜测值
#constraints=con, bounds=bd 这个是约束条件，bound要求的是一个包含范围的列表

print(res)
```

返回值:
`res` 是一个 `OptimizeResult` 对象（类似字典），包含以下重要字段：

- `res.x`：最优解，即最小化目标函数时 x0,x1x0​,x1​ 的值。
    
- `res.fun`：目标函数在最优解处的值。
    
- `res.success`：是否成功找到最优解（布尔值）。
    
- `res.message`：优化过程的终止信息。
    
- `res.nit`：迭代次数。
    
- 其他如 `res.jac`（梯度）等。
