拉格朗日定理的意义在于把有约束的转化为无约束的

解释：目标函数的梯度与约束函数的梯度的线性组合垂直

###  实际意义：怎么用这个定理？

求解等式约束优化问题（如最小化 f(x)，满足 hj(x)=0）：

1. 写出拉格朗日函数 L(x,λ)。

# 凸优化

### **凸集概念：**

设 C是某个实向量空间（例如 Rn）中的一个子集。若对任意两点 x,y∈C 以及任意实数 λ∈[0,1]，都有：

λx+(1−λ)y∈C

则称 C 为**凸集**。

换句话说，就是凸集内任意两点的线段就完全包含在集合内

### 凸函数：
