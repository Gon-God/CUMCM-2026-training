# 字符串处理
- 索引值从0开始
- 取特定位函数：函数名[ : ]
- 找特定字符串的位置函数：
```python
.find()##取第一次出现的位置 
.rfind()##取最后出现的位置
.index()##同find
.rindex()
.count()##出现的次数
```
- 将字符串转为列表：split(), rsplit()
- ```python
  .split("分隔的符号") #从右开始
  #如果不指定，默认删除空白
  .rsplit()
  
  #example
  text = "apple, banana"
  result = text.split(",") 
  --> result['apple', 'banana']
  ```
- 将列表转为字符串：join()
```python
"连接的符号".join(原列表)

#example
words = ["Hello", "world", "Python"]
result = " ".join(words)   # 用空格连接
print(result)  # "Hello world Python"

result2 = ",".join(words)  # 用逗号连接
print(result2) # "Hello,world,Python"
```
- 删除两端空格或者指定字符:strip()
```python
.strip("指定字符，不加就是删除空白")#删除两端
.lstrip()#删除左端
.rstrip()#删除右端
```
- 检测是否以指定字符串开始或者结束
```python
.startwith()
.endwith()
```

# 集合

- 集合是**无序的，不能重复的**
- 如果有重复元素，会自动删除
- 每一次寻求集合，输出的顺序都不一样
- 创建一个集合：set()
```python
a = set("abac")
-->{"a", "c", "b"}#每一次结果都不一样
```

# 字典
- 由{key:value, ...}的形式组成
- key必须是唯一的，value可以不唯一
- value可以取任意数据类型，但是key是不可变的
```python
a = {"a":"1", "b":"2"}

a["a"]#输出“1”

a["c"] = "3" #增加一个元素
a["a"] = "3" #修改一个元素
```
- get()提供由不存在key时候返回指定值，避免空值报错
- 语法：get(key, "不存在key的时候输出的指定值")
```python
a = {"a":"1", "b":"2"}

a.get('a', 'not exist') --> outcome:"1"
a.get('c', 'not exist') --> outcome:"not exist"
```
