
利用sympy.dsolve()函数，能求出解析解
利用y(x).diff(x,n)得到求n阶导


求解微分方程$y^{'}=-2y+2x^2+2x$, $y(0)=1$
```python
import sympy as sp

sp.var('x')
y=sp.Function('y')

eq = y(x).diff(x)+2*y(x)-2*x**2-2*x #y(x).diff(x)是微分
s=sp.dsolve(eq,ics = {y(0):1}) #求解

s=sp.simplify(s)
print(s)
```

参数ics是初值，边值条件，所有的约束条件，key是式左边，value是式右边
