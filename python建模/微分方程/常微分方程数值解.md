

一般运用龙格-库塔方法求解
运用函数：`scipy.integrate.odeint(fune,y0,t)`

fune是定义微分方程的函数
y0是初始条件的序列
t是一个自变量取值的序列

返回值
sol是对应序列t中元素的数值解
由n个函数组成的微分方程组，sol返回n列的矩阵对应每个函数的t解，行是对应每个t的解


例:
![[Pasted image 20260612151231.png]]

```python
from scipy.integrate import odeint
import numpy as np
import pylab as plt
import sympy as sp


dy = lambda y, x: -2*y +2*x**2+2*x
xx = np.linspace(0,3,31) #从0到3取了31个等距离数,作为t
s = odeint(dy,1,xx)
print('x=',xx,'对应的数值解为y=',s.flatten())
#fatten()将多维数组展开为一维数组

#画图y关于x的函数
plt.plot(xx,s, "*")

#看看与解析解有什么不同
sp.var('x');y=sp.Function('y')
eq = y(x).diff(x)+2*y(x)-2*x**2-2*x
s2 = sp.dsolve(eq, ics={y(0):1})
expr = s2.rhs
print(s2.rhs)
print(s2)
sx = sp.lambdify(x,expr,'numpy')
#这里是将scipy里面的Function转回能画图的匿名函数
plt.plot(xx,sx(xx))

plt.show


```
