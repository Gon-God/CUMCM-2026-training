# K均值聚类

先划分C个子集
定义聚类中心为$m_i$
$J_c$最小的聚类就是最优结果
![[Pasted image 20260616174528.png]]


算法如下：
1. 初始化：先将样本集G任意分类为$G_i$
2. 算出每一类的m，与j
3. 现在有了“临时中心”了，就按规矩来——把所有点拿出来，**重新排队**，谁离哪个中心近，就正式加入谁的门下。全部排完之后，**再根据这些新队伍，重新计算新的中心点**（均值），并重新计算新的“混乱程度” Jc​
4. 如果这次算出来的新中心，和上次的位置一模一样（或者混乱程度不再降低），说明队伍已经稳定了

---

`sklearn.cluster.KMeans(n).fit()` 提供了 K均值聚类的算法
n为形成簇的数量

`.label()`会生成一个**每一个样本点**最终被分配到的簇的标签索引
 `.cluster_centers_`提供了所有簇的最终点的坐标，即中心位置在哪里
 `.inertia_` 提供了该k值的离差平方和

```python
from sklearn.cluster import KMeans

import numpy as np

  

a = np.array([[1,3],[2,4],[3,5],[8,10],[9,11]])
```

# 最佳K值的确定

即k值给多少合适？

### 簇内离差平方和拐点法

即计算所有的k值下的离差平方和。用可视化的方法找到拐点

```python
from sklearn.cluster import KMeans
import pylab as plt
import numpy as np

a = np.array([[1,3],[2,4],[3,5],[8,10],[9,11]])
md = []
g = np.arange(2,len(a)+1)
for i in range(2,len(a)+1):
    md.append(KMeans(n_clusters=i).fit(a).inertia_)

plt.plot(g,md,'*-')
plt.show()
```

k必须是从2开始，分为2簇才有意义

### 轮廓系数法

**同时衡量聚类结果的“紧密度”和“分离度”**——即看看同一个簇内的样本是否足够相似（内聚），不同簇的样本是否足够不同（分离）

首先要对数据进行归一化处理
### 1. 核心计算逻辑（针对单个样本）

对于数据集中的任意一个样本点 i，它的轮廓系数 s(i)通过以下三步计算：

- **计算 a(i)（内聚度）**：样本 i 到**同簇**内其他所有样本的平均距离。这个值越小，说明该点与同簇成员越紧密。
    
- **计算 b(i)（分离度）**：样本 i 到**其他最近簇**（即相邻最近的那个簇）内所有样本的平均距离。这个值越大，说明该点与别的簇隔得越开。
    
- **计算该点的轮廓系数**：
    
    s(i)=b(i)−a(i)max⁡{a(i),b(i)}

### 2. 如何解读数值？

单个样本的 s(i) 取值范围在 **[-1, 1]** 之间：

- **接近 +1**：说明 b(i)远大于 a(i)，即样本离自己簇很近，离邻近簇很远。**聚类效果极佳**。
    
- **接近 0**：说明 a(i) 约等于 b(i)，样本位于两个簇的边界上。**存在重叠，聚类效果模糊**。
    
- **接近 -1**：说明 a(i) 大于 b(i)，样本离其他簇比离自己簇还近。**样本可能被错误分配到了错误的簇中**。
    

**整体轮廓系数**：将所有样本点的 s(i) 取平均值，就是整个模型的轮廓系数。**这个平均值越高，代表整体聚类效果越好**（通常 > 0.5 可认为聚类有效，> 0.7 表示效果相当显著）。
