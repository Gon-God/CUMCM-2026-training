
距离相近的样品先聚为一类，距离远的后聚成类，这样每个样品总能聚到合适的类中。

1. 将每个样品都独自聚为一类，构造n个类
2. 根据距离公式，构造出距离矩阵，记为$D_{(0)}$ 
3. 把距离最近的两类归为一新类，其他样品依然独自聚类，聚为n-1类
4. 计算新类与当前各类的距离，将最近的两个类聚为一类。
5. 重复以上过程，直到所有样品都聚为一类
6. 画聚类谱系图
7. 决定类的格式以及各类包含的样品数，做出解释


对类之间的距离，有不同的定义方法

### 最短距离法

两类之间最邻近的两样品之间的距离
$D_{ij} = \min d(\omega_s \omega_t)$


聚类步骤：
1. 找出$D_{(0)}$的非对角线的最小元素，为$d_{pq}$ ，坐标pq，则将$G_p和G_q$  合并为一个新类

```python
import scipy.cluster.hierarchy as sch

import numpy as np

import pylab as plt

  

import matplotlib.pyplot as plt

plt.rcParams['text.usetex'] = False   # 强制使用 Matplotlib 内置渲染器

  

#plt.rc('text',usetex=True)

plt.rc('font')

c = sch.linkage(a, method='single')

s = ['$\\omega_'+str(i+1)+'$' for i in range(5)]

dendrogram = sch.dendrogram(c,labels=s)

plt.show()
```

method = 'single'就是最短距离法

## 最长距离法

这里是计算类里面距离最长的元素，与最小距离法类似

用的是c = sch.linkage(b, method='complete')

import numpy as np
