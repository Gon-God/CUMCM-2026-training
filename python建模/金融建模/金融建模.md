# 市场有效性假设（EMH）

任何可用于预测股票表现的信息已经在股价中反应出来
- 投资者只能得到于股票风险相称的收益率
- 股价呈现随机游走的状态

一共有三种形式
1. 弱势有效：已经反映了全部能从**市场交易数据**中得到的信息。股票的历史价格信息已经被市场充分消化，不可能通过分析市场的价格趋势分析获利
2. 半强式有效：**全部公开信息**，投资者能从公开渠道中获取的信息都会被反应在股价里面
3. 强势有效：反映了**全部信息**，包括内幕消息

# 期货
双方约定在未来某一时间以特定价格买卖资产的合约

# 期货
一种合约，赋予持有人在未来以特定价格买入或卖出资产的权力

# 套利
利用两个或多个市场之间的价格差异，**无风险**获利的策略

# 对冲
用一种资产或者金融工具来抵消另一种资产的风险，比如同时投资于债券，股票期权
