**差分方程模型** 是一种用来描述某个变量在**离散时间点**上的变化规律的数学工具。它刻画的是：系统下一时刻的状态与当前时刻（以及过去有限个时刻）的状态之间的函数关系。

简单来说，如果你把时间看作一个接一个的“步数”（第1步、第2步、第3步……），那么差分方程就能告诉你：**从当前这一步，如何推算出下一步**。

一个典型的差分方程长这样：
$$
y_{n+1} = f(y_n, y_{n-1}, \dots, n)
$$
其中 $( y_n )$ 表示第 $( n )$ 个时刻的状态值。

### 核心特点
- **时间离散**：只在 $( n = 0, 1, 2, \dots )$ 等整数点上定义，不关心连续变化过程。
- **递推驱动**：知道初始状态（比如 \( y_0 \)），就可以一步一步推算出未来所有时刻的状态。

## 1.斐波那契数列通项

$F_{k+2} = F_k + F_{k+1}$

将二阶差分方程式化为一阶方程式

$α_0$是已知的
于是，问题变成了求解$A^k$的问题
我们一般用对A对角化分解来求$A^K$

利用代码来求解
```python
	a = sp.Matrix([[0,1],[1,1]])
	var = a.eigenvals()
	vec = a.eigenvectors()
	P,D = a.diagonalize() #把A对角化
	ak = P @ (D ** k) (P.inv()) #得出AK
	F = ak@ sp.Matrix([1,1]) #求αk
	s = sp.simpify(F(0)) #简化
```

## 解法3:用SymPy库直接解

```python
import SymPy as sp
sp.var('k')
y = sp.Function('y')
s = sp.rsolve(y(k+2)- y(k+1) - y(k) = 0, y(k), {y(0):1,y(1):1})
print(s)
```
